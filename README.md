# Mira Media Website

Animated Next.js marketing site for Mira Media, cloned from the Ether Studio template with the same motion system, mesh background, and visual language.

## Run

```bash
cd mira-website
npm install
npm run dev
```

## Content

Marketing copy lives in `src/data/*.json`. IAB compliance file is at `public/sellers.json`.

## Routes

- `/` — Home
- `/advertisers` — Demand side
- `/publishers` — Supply side
- `/about` — Mission & principles
- `/contact` — Dual-funnel partnership form
- `/technology` — Protocol & video specs
- `/brand-safety` — sellers.json transparency
- `/sellers.json` — Static IAB sellers file
